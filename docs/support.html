Tab Guard Support

Tab Guard BETA is currently a closed testing release.

Report a problem

Open Tab Guard → Settings → Diagnostics & feedback. If a legitimate page was blocked, mark it This was wrong, then use Copy latest diagnostic.

Send the copied diagnostic together with a short description of what you expected to happen to: tabguard@sharkinfestedcustard.net

Privacy

Diagnostics are not transmitted automatically. You choose whether to copy and send a diagnostic report.
