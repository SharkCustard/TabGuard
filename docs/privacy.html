Tab Guard Privacy Policy

Last updated: 16 September 2026

Summary: Tab Guard analyses browser tab and navigation behaviour locally to detect suspicious tab hijacking. The current closed beta does not upload browsing history, page content, protection history, site rules or diagnostic data to the developer or third parties.

What Tab Guard processes

To provide its tab-hijack protection, Tab Guard processes web browsing activity necessary for that feature, including website domains/URLs, top-level navigation events, navigation timing, whether tabs/windows were created, and limited user-interaction signals associated with links or window-opening behaviour.

Tab Guard does not collect page text, form contents, passwords, authentication cookies, payment information, personal communications, screenshots, or general page content.

How this information is used

The information is used only to detect and respond to suspicious multi-tab navigation behaviour, apply site rules chosen by the user, show recent protection history, and provide local diagnostics.

Local storage

Protection settings, site rules, recent block history, diagnostic state and beta-licence state are stored locally in Chrome. Users can clear relevant history/rules from the extension settings or remove the extension to remove its locally stored extension data.

Data transmission and sharing

The current closed beta does not transmit browsing history, page content, site rules, protection history or diagnostic data to the developer, advertising networks, analytics services or other third parties.

Tab Guard does not sell personal data or browsing data and does not use browsing activity for advertising, profiling, creditworthiness or lending.

Beta Tester Pass

The closed beta may use an installation-bound Beta Tester Pass. The extension generates a random local installation identifier and derives a non-personal Install Code from it. The Install Code is not an email address, account name, hardware serial number or advertising identifier. The signed pass contains a random pass ID, expiry date and Install Code.

Chrome permissions

Tab Guard uses Chrome permissions for tabs, navigation and local storage, plus page access on ordinary HTTP/HTTPS websites. Broad page access is necessary because suspicious tab-displacement behaviour can occur on any website. Access is limited to the extension's user-facing protection purpose.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Tab Guard uses browser data only to provide or improve its disclosed tab-protection purpose and does not use or transfer that data for personalised advertising.

Changes

This policy may be updated as Tab Guard develops. Material changes to data practices will be reflected here and, where required, disclosed before the changed practice takes effect.
