Tab Guard Privacy Policy

Last updated: 16-10-2026

Summary: Tab Guard analyses browser tab, navigation and limited user-interaction signals locally to detect suspicious tab hijacking. It does not automatically upload browsing history, page text, protection history, site rules or diagnostic data to the developer or third parties.

What Tab Guard processes

To provide tab-hijack protection, Tab Guard processes the browsing information needed for that purpose, including website domains/URLs, top-level navigation events and timing, whether tabs or windows were created, and limited user-action signals associated with links or window-opening behaviour.

Where necessary to understand a user-triggered navigation, Tab Guard may process a link destination URL or similar hyperlink information. It does not scrape or collect general page text, form contents, passwords, authentication cookies, payment information, personal communications, screenshots, images, audio or video.

How this information is used

The information is used only to detect and respond to suspicious multi-tab navigation behaviour, apply site rules chosen by the user, show recent protection history, provide local diagnostics and operate Tab Guard's user-facing protection controls.

Local storage

Tab Guard stores extension settings locally in Chrome, including protection mode, site rules, recent protection history, diagnostic state, onboarding/update state, a random installation identity, and whether a first-site protection notice has already been shown. Temporary decision state may also be stored for the current browser session.

The random installation identity is generated locally and is not based on a user's name, email address, hardware serial number, browsing history or advertising identifier.

Data transmission and sharing

Tab Guard does not automatically transmit browsing history, page text, site rules, protection history or diagnostic data to the developer, advertising networks, analytics services or other third parties.

If a user chooses to send feedback, Tab Guard may prepare basic version, mode and installation details for the user to copy or send. The user decides whether to provide that information. Browsing history is not automatically included or transmitted.

Tab Guard does not sell personal data or browsing data and does not use browsing activity for advertising, profiling, creditworthiness or lending.

Chrome permissions and website access

Tab Guard uses Chrome permissions for tabs, navigation and local storage, plus access to ordinary HTTP/HTTPS pages. Broad website access is necessary because suspicious tab-displacement behaviour can occur on any website. That access is used only for Tab Guard's disclosed protection purpose.

Chrome Web Store data disclosures

Because Tab Guard must inspect navigation URLs, user-triggered link/window activity and limited hyperlink information to detect hijacking, the Chrome Web Store may classify the data it processes under categories including Web history, User activity and Website content. This processing is local to the browser unless the user deliberately chooses to send feedback.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Tab Guard uses browser data only to provide or improve its disclosed tab-protection purpose and does not use or transfer that data for personalised advertising.

Changes

This policy may be updated as Tab Guard develops. Material changes to data practices will be reflected here and, where required, disclosed before the changed practice takes effect.
